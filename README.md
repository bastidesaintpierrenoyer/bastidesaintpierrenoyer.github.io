# Bastide Saint-Pierre Noyer

Site web statique multilingue (français / anglais) pour la location d'une bastide provençale à Saint-Zacharie, au pied de la Sainte-Baume.

## Généré avec

- [Hugo](https://gohugo.io/)
- Thème [graysx](https://github.com/akatiggerx04/graysx-hugo)

## Développement local

```bash
hugo server -D
```

## Déploiement

```bash
hugo
# Pousser sur origin, GitHub Pages déploie automatiquement
```

## Structure

- `config.toml` — Configuration du site et des langues
- `data/fr/homepage.yml` — Contenu de la page d'accueil (français)
- `data/en/homepage.yml` — Contenu de la page d'accueil (anglais)
- `i18n/fr.yaml` — Traductions de l'interface (français)
- `i18n/en.yaml` — Traductions de l'interface (anglais)
- `themes/graysx/` — Thème Hugo
- `static/assets/img/` — Photos de la propriété
